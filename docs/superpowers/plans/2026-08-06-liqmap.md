# LiqMap Implementation Plan

> **For agentic workers:** Executed inline in-session via superpowers:executing-plans.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A static PWA that computes and renders a Bybit liquidation heatmap entirely
client-side.

**Architecture:** Strict one-way layering `ui → data → engine`. The engine is pure and
synchronous (no React, no network) so it is unit-testable in isolation; the data layer owns
all I/O; React only orchestrates and paints.

**Tech Stack:** Vite 7, React 19, TypeScript 5, Vitest 3, canvas 2D. No runtime deps beyond
React — nothing that would block a Capacitor wrap.

---

## File Structure

| File | Responsibility |
|---|---|
| `src/engine/types.ts` | `Candle`, `OiPoint`, `Mode`, `HeatmapData`, `Grid` |
| `src/engine/tiers.ts` | mode↔interval map, tier leverages, capital split, liq-price math |
| `src/engine/grid.ts` | build 1100-bucket grid; `priceToBucket`/`bucketToPrice`/`rangeToBuckets` |
| `src/engine/oi.ts` | align OI to candles, forward-fill, `oiFactor` |
| `src/engine/seed.ts` | `clearRange` and `seedCandle` on the active level vectors |
| `src/engine/normalize.ts` | `percentile` over non-zero values; `computeVmax` |
| `src/engine/build.ts` | candles + OI → per-tier Float32 matrices (clear→seed→snapshot) |
| `src/engine/colormap.ts` | inferno LUT, `scoreToRgba` |
| `src/engine/bands.ts` | extract strongest bands from the latest column (watchlist/alerts) |
| `src/data/rest.ts` | `fetchKlines`, `fetchOpenInterest` (cursor pagination), `fetchTicker` |
| `src/data/ws.ts` | `BybitSocket`: subscribe, 20s ping, backoff reconnect, callbacks |
| `src/data/cache.ts` | TTL memo used by the watchlist |
| `src/ui/HeatmapCanvas.tsx` | offscreen raster + upscale, overlays, zoom/pan/crosshair |
| `src/ui/Toolbar.tsx` | symbol presets, custom symbol, interval, tier toggles |
| `src/ui/Watchlist.tsx` | five symbols, live price, distance-% to nearest strong band |
| `src/ui/Settings.tsx` | alert threshold + proximity %, notification permission |
| `src/ui/StatusBar.tsx` | connection pill, candle count, vmax, errors |
| `src/ui/hooks/*.ts` | `usePersisted`, `useHeatmap`, `useLive`, `useWatchlist`, `useAlerts` |
| `src/App.tsx` | composition + layout |
| `public/manifest.webmanifest`, `public/sw.js` | PWA shell |
